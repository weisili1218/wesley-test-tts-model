# 這份是從官方 CosyVoice requirements.txt 改寫來的。跟官方的差異與原因：

#   torch / torchaudio     → 官方釘 2.3.1+cu121，沒有能跑 sm_121 的 aarch64 build。
#                            改在 Dockerfile 用 cu130 index 裝 2.11.0。
#   onnxruntime-gpu        → PyPI 沒有 aarch64 wheel。改用 CPU 版；ONNX 只跑
#                            speech tokenizer 跟 campplus（都是短音檔），CPU 夠用。
#   deepspeed              → 只有 cosyvoice/utils/train_utils.py 用到（訓練用），
#                            推論路徑完全沒 import。
#   tensorrt-cu12          → 只有 load_trt=True 才需要，而且是 cu12。我們不開 TRT。
#   gradio                 → 只有 demo 用得到，拿掉省時間跟相依衝突。
#   modelscope             → 我們用 huggingface_hub 下載，不需要它。
#   ttsfrd                 → 只有 x86_64 wheel。frontend.py 有 try/except，
#                            import 失敗會自動 fallback 到 wetext。
#
# 特別說明 wetext：官方新版已經從 WeTextProcessing(pynini) 換成 wetext(kaldifst)，
